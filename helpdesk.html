📧 Configuración de Correo (Gmail)

Para enviar notificaciones automáticas al técnico asignado, conecta la cuenta contecadocs@gmail.com usando el botón "📧 Conectar Gmail" en la barra superior. El correo se enviará automáticamente cada vez que se cree un ticket con un técnico que tenga email registrado.

Requisito: La Gmail API debe estar habilitada en el proyecto de Google Cloud (393065960730). Si es la primera vez, ve a Google Cloud Console → Gmail API → Habilitar.
